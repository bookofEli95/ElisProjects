# ElisProjects

IBM i (AS/400) source: RPGLE, CLLE, DDS and SQL members, stored flat in the repo root.

## Branch rules (set by Eli)

- **One branch per chat.** Start a new branch at the beginning of a chat and use that
  one branch for the entire chat. Never create extra branches mid-chat.
- **Never keep the same program on several branches.** There is no reason to have
  multiple branches holding the same programs. The newest version of every program
  lives on the default branch, so start each chat's branch from the latest default
  branch, never from an older branch.
- **Finish by consolidating.** When a chat's work is done, bring it into the default
  branch (with Eli's go-ahead) so the next chat starts from the newest code, then tell
  Eli the chat's branch is redundant and can be deleted.
- **Delete only when asked.** Do not delete branches unprompted. Before any deletion,
  confirm every commit on the branch is already contained in the default branch.
